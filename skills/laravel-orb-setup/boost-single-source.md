# Boost: one source of truth in `.ai/`

An app change, made in its own thread after the user approves it (see the skill's "Changes to
the app"), never by orb setup itself. Commit it as its own change for the team to review.

Boost copies every guideline and skill into each agent's own files (`AGENTS.md`, `CLAUDE.md`,
`.agents/skills`, `.claude/skills`, `.cursor/skills`, ...), so committing that output duplicates
every skill per agent. Laravel's starter kits gitignore all of it, including `boost.json`, the
per-developer agent list, and each checkout regenerates it with `boost:install`; in orbs,
`.agents/setup` does that when `boost_install=1`.

- If `laravel/boost` is not in `composer.json`, run `composer require laravel/boost --dev`.
- Move hand-written content out of generated files before untracking them. Text in
  `AGENTS.md` or `CLAUDE.md` outside the `<laravel-boost-guidelines>` block goes to
  `.ai/guidelines/<topic>.md`. A tracked skill folder in any agent's skills directory that
  Boost does not generate (not in `boost.json`'s `skills` and not from a Composer package)
  moves to `.ai/skills/<name>/`. Keep `.ai/rules/`; Boost's `record-rule` tool writes the
  team's rules there, except the generated `.ai/rules/boost/`.
- Add Boost's output paths to `.gitignore`, from the installed Boost (below).
- Untrack what is now ignored: review `git ls-files -ci --exclude-standard`, then run
  `git ls-files -ci --exclude-standard -z | xargs -0 -r git rm --cached -q`.
- If the team keeps a hand-written `CLAUDE.md` as its source of truth (it is tracked and has
  content outside the Boost block, or the user says so; ask when unsure), keep it instead of
  moving it into `.ai/guidelines`. Boost cannot write around it: Amp reads `CLAUDE.md` only
  when there is no `AGENTS.md`, and Boost would otherwise append its block into the committed
  file. So send Boost's output to a gitignored file that `CLAUDE.md` imports:
  - Remove the `<laravel-boost-guidelines>` block from `CLAUDE.md` and add a line
    `@.ai/boost.md`, outside any code block. Move any tracked `AGENTS.md` content into
    `CLAUDE.md`.
  - In `config/boost.php` (create it with only this key if it does not exist; Boost merges
    its defaults), set `'agents' => ['amp' => ['guidelines_path' => '.ai/boost.md'],
    'claude_code' => ['guidelines_path' => '.ai/boost.md']]`, with a comment saying why.
  - In `.gitignore`, drop `/CLAUDE.md` and add `/.ai/boost.md`. Keep `/AGENTS.md` ignored: a
    local `AGENTS.md` would hide `CLAUDE.md` from Amp. If teammates use other agents that
    write `AGENTS.md`, give them the same `guidelines_path` in `config/boost.php`.

## Boost's output paths

Ask the installed Boost where each agent writes instead of keeping a list here, so new agents
and moved files are covered by whatever version the app runs. Under the comment
`# Laravel Boost output, generated by php artisan boost:install. Edit .ai/ instead.`, add each
path this prints, plus `/CLAUDE.md` (Claude Code writes `AGENTS.md` unless a `CLAUDE.md`
exists; leave `/CLAUDE.md` out when the team keeps a hand-written one):

```bash
php artisan tinker --execute '
$paths = ["boost.json", ".ai/rules/boost/"];
foreach (app(Laravel\Boost\BoostManager::class)->getAgents() as $class) {
    $agent = app($class);
    if ($agent instanceof Laravel\Boost\Contracts\SupportsGuidelines) $paths[] = $agent->guidelinesPath();
    if ($agent instanceof Laravel\Boost\Contracts\SupportsSkills) $paths[] = rtrim($agent->skillsPath(), "/")."/";
    if ($agent->mcpConfigPath()) $paths[] = $agent->mcpConfigPath();
}
foreach (array_unique($paths) as $p) echo "/".preg_replace("#^(\./|".preg_quote(base_path()."/", "#").")#", "", $p)."\n";
'
```

Skip paths the repository already ignores, and `/.amp/settings.json` when the Amplify entries
cover `.amp/`.

Afterwards, teammates run `php artisan boost:install` once in their local checkout, because
Boost's generated files are no longer committed.
